# Multimens

Python 3 tool suite for the computation of memory kernel matrices from a set of time series data.

To get started, run

    pip install .

to install. See `example/example_extraction.ipynb` for an introduction of the extraction scheme, and `example/example_embedding.ipynb` for an introduction of the embedding scheme. The notebok `example/fitting_multi_dim_kernels_exp_matrices.ipynb` includes an instruction to fit multi-dimensional memory kernels with multi-exponential matrices.
